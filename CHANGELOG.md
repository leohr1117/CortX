# Changelog

## 1.14.4

Notes are now stored as structured documents. All your existing notes were carried over unchanged.

## 1.14.3

The note header now shows only the topic, and on iPad in window mode the back button is no longer covered.

## 1.14.2

Internal cleanup, nothing changes for you.

## 1.14.1

List markers keep a gap before the words while you edit, same as when you read.

## 1.14.0

Numbered lists can use 1., A., a., I., or i. Enter adds the next item of the same kind, and pasting that Markdown formats it at once. The formatting bar switches the kind, or turns the line into a list, a task, or plain text.

## 1.13.1

Internal cleanup, nothing changes for you.

## 1.13.0

Capture on the start page shows formatting while you write. Bold, italic, strikethrough, important, and code can sit inside each other. Pasting Markdown shows lists, tasks, and the same formatting. A line like #topic/page stays text.

## 1.12.1

In a note, - , [] and # at the start of a line become a list, a task, or a heading. **text**, *text*, ~~text~~, !!text!! and `text` become formatting. Backspace right after restores the characters. With shortcuts off, what you type stays as typed and is saved so it does not format on the next open.

## 1.12.0

Editing a note shows formatting without the marker characters. Checkboxes in a note can be toggled, and they stay toggled after a reload.

## 1.11.1

Internal cleanup, nothing changes for you.

## 1.11.0

Enter in a list or task adds the next item of the same kind, and a new checkbox is unchecked. Enter on an empty item ends the list. Shift+Enter breaks a line inside the item. Backspace at the start of an empty item turns it into a normal line.

## 1.10.0

A format on several selected lines applies to each line. If every selected line already has it, the format comes off.

## 1.9.0

Deleting one side of bold, italic, strikethrough, important, or code removes the other side too. The words in between stay.

## 1.8.13

Internal cleanup, nothing changes for you.

## 1.8.12

A topic lists each page on one line. A long title ends in an ellipsis, and the day it was filed sits beside it.

## 1.8.11

You can close the update message. It stays closed after a reload.

## 1.8.10

Filing, deleting, and moving shows one short message above the keyboard. Undo on that message puts the change back. The message fades on its own, or when you dismiss it.

## 1.8.9

Words that are both important and code show the gold highlight and the code font. The order of those two formats does not change the highlight.

## 1.8.8

Housekeeping only. CortX looks and works the same.

## 1.8.7

Bold, italic, strike, important, and code can be turned on and off with the format buttons in any order, including when they are nested. Turning one off removes only that format. The button shows whether it is on.

## 1.8.6

Undo after filing puts the text back into the capture field. The note you just filed is removed. A note that was split across pages comes back as one text.

## 1.8.5

The row that creates a topic, page, or section stays at the bottom of suggestion lists and of the topic picker. The matches above it scroll, and the last match stays reachable.

A topic written without a page, such as #topic, still files a new page in that topic.

## 1.8.4

Lists of pages, topics, and suggestions scroll on a phone with a finger, and with the mouse wheel on a computer. The last entry stays reachable, including while the keyboard is open.

On a phone, the format bar sits on the bottom edge. The File button and the target line sit above it. While the keyboard is open, the bar sits on the keyboard.

## 1.8.3

The page title is the first line of the note. It can be a heading or a normal paragraph. A new page is not turned into a heading. A heading that is already there stays a heading. Sections stay level-two headings.

## 1.8.2

On a phone, the format bar sits on the keyboard while it is open. When the keyboard closes, the bar drops back above the File button. On a note, it sits on the bottom edge.

## 1.8.1

A line that starts with #topic/page files that part of the note. One note can go to several pages. Text before the first such line goes to the Inbox. A #tag in the middle of a line stays in the text.

An empty topic stays in the library and shows 0 pages until you delete the topic. Deleting the last page shows Page deleted, and Undo brings it back.

## 1.8.0

A topic lists its pages. The page title is the first heading, and sections are the level-two headings on that page.

While you capture, #topic/page/section shows where the note goes and files it there. You can undo that. An open editor is never overwritten.

## 1.7.3

The start page uses the same editor as a note. The format bar and typing shortcuts work while you capture. Topic tags stay colored, and Enter on a phone does not file the note.

## 1.7.2

Bold, italic, strike, and Wichtig can be used together. A space at the end of a note stays when you save. On a phone, the selection sits on the text, and the format bar icons are clearer.

## 1.7.1

Updates arrive more reliably. The installed app picks up the new version.

## 1.7.0

You can mark something as Wichtig. !!text!! highlights words, and !!!! at the start of a line marks that line, with a bar on the left. The format bar has a Wichtig button. The saved note stays plain text.

## 1.6.0

Notes stay as text. Bold, italic, strike, code, lists, checkboxes, links, and headings show while you read. The editor keeps that text, with a format bar and optional shortcuts while typing.

## 1.5.5

Housekeeping only. CortX looks and works the same.

## 1.5.4

Change password in a password manager opens the Stride page.

## 1.5.3

What's new lists each version, newest first. After an update, CortX tells you once. A dot on the library menu stays until you open What's new.

## 1.5.2

Sign in with a password manager. The username stays if the password is wrong, and you can show the password while you type. Change your password in Stride.

## 1.5.1

The home screen name is CortX. The icon is three lines of a note, the top one white and the ones under it gray, on a full dark square. A maskable icon fills the phone's shape, so no white ring shows around it.

## 1.5.0

A note opens on its own page. Inbox, a topic, and search show the whole note, with its lines and formatting. Tap a note to read it. The pencil turns that same page into a writing surface. The read icon saves and shows the note again. Edits also save on their own and when you go back. A draft stays on the device, including while you are offline. Change the topic or delete the note from the menu, and undo a delete. The old edit form is gone.

## 1.4.1

Sign in with your Stride username and password. The sign-in field is a username. A wrong password, too many attempts, or a sign-in Stride cannot accept is reported as that. If Stride cannot be reached, try again later.

## 1.4.0

Reading a note can show a date. A date or a time in the text, in English or German, shows under the note: "tomorrow 3pm", "morgen 15 Uhr", "next Monday", "03.11.", a weekday, or a clock time such as "15:30". It shows on a topic, in Inbox, and in search results. The day is taken in Europe/Berlin from when the note was written. The saved text stays plain. Capture and edit stay as they are.

## 1.3.0

A note can have a heading. In edit, Heading marks the line at the cursor, or turns that heading back into a normal line. A heading is a line that starts with "= ". Reading shows it on a topic, in Inbox, and in search results. The saved text stays plain. #topic is still a tag. Capture stays a plain text field.

## 1.2.0

Notes show light formatting while you read them. A line that starts with "- " becomes a list, "[]" and "[x]" become checkboxes, and text between double asterisks is bold. This shows on a topic, in Inbox, and in search results. The saved text stays plain. Capture and edit stay text fields.

## 1.1.0

Search your notes from the library. The field looks through every topic and Inbox. Each match shows the note and its topic, newest first. Open a match to read that note where it was filed.

## 1.0.0

The first release of Cortex. Write a note and move on. The app files it for you.

Sign in with your Stride account. Your notes stay with that account. Change your password in Stride, and sign out from the library. A draft stays on the device while you are offline, and notes you file offline sync after you sign in.

File from the capture screen with File or Ctrl/Cmd+Enter. A #topic picks the topic. Without one, the note goes to Inbox. Change the topic right after filing. The library lists your topics. Rename, merge, or delete a topic, and undo. Edit or delete a note, and undo.
